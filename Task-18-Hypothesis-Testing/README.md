# Task 18 – Hypothesis Testing Fundamentals

## Objective
To understand the fundamentals of statistical hypothesis testing by formulating null and alternative hypotheses and performing basic hypothesis tests.

## Tools Used
- Python
- Pandas
- NumPy
- SciPy
- Jupyter Notebook / Google Colab

## Tasks Performed
- Defined null and alternative hypotheses.
- Selected an appropriate significance level of 0.05.
- Performed a One-Sample t-test.
- Performed an Independent Two-Sample t-test.
- Performed a Chi-Square test.
- Calculated test statistics and p-values.
- Interpreted the results based on the selected significance level.

## Hypothesis Tests

### 1. One-Sample t-test
Used to determine whether a sample mean is significantly different from a specified value.

### 2. Independent Two-Sample t-test
Used to determine whether the means of two independent groups are significantly different.

### 3. Chi-Square Test
Used to determine whether two categorical variables are independent or associated.

## Conclusion
Hypothesis testing provides a systematic way to make decisions using sample data. The null and alternative hypotheses were formulated before each test, and test statistics and p-values were used to reach conclusions.

A p-value below 0.05 provides sufficient evidence to reject the null hypothesis. A p-value equal to or above 0.05 indicates that there is not enough evidence to reject the null hypothesis.
