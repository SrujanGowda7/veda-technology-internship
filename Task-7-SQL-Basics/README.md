## 1. Project Overview

This project focuses on building foundational SQL skills required for entry-level Data Analyst and Data Science positions.

The Chinook business database was used to practice retrieving, filtering, sorting, grouping, and aggregating business records using SQL.

A total of 25 SQL queries were created to analyze customers, invoices, tracks, genres, countries, employees, and sales.

The main objectives of this task were:

- To understand basic SQL syntax.
- To retrieve records using SELECT.
- To filter records using WHERE.
- To sort records using ORDER BY.
- To group records using GROUP BY.
- To filter aggregated results using HAVING.
- To perform calculations using aggregate functions.
- To use JOIN operations to combine related tables.

## 7. Business Insights

### Insight 1 – Geographic Sales

Grouping sales by billing country helps identify the strongest geographic markets. This information can help businesses focus marketing and customer-retention strategies on high-performing markets.

### Insight 2 – Customer Spending

Customer-level revenue analysis helps identify high-value customers. These customers could be targeted through loyalty programs, personalized offers, and retention strategies.

### Insight 3 – Product Pricing

Analyzing minimum, maximum, average, and highest track prices provides an understanding of the product pricing range within the music catalog.

### Insight 4 – Product Categories

Grouping tracks by genre shows which music categories have the largest catalogs. This can help businesses understand the composition of their product offerings.

### Insight 5 – Sales Performance

Analyzing sales associated with employees provides a way to compare sales performance and understand how revenue is distributed across sales-support representatives.
