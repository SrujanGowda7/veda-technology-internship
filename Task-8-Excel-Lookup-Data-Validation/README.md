# Task 8 – Excel Lookup Functions & Data Validation

## Veda Technology – Data Science Internship

**Track:** Data Science  
**Task:** Level 1 – Day 8  
**Topic:** Excel Lookup Functions & Data Validation  
**Tool:** Google Sheets / Microsoft Excel

## Objective

The objective of this task was to develop practical spreadsheet skills for combining business information and improving data quality.

## Concepts Used

- XLOOKUP
- INDEX-MATCH
- IFERROR
- Data Validation
- Duplicate ID checking

## Dataset

An Employee and Department dataset was created containing:

- Employee ID
- Employee Name
- Department ID
- Department Name
- Manager
- Salary

## Work Performed

### XLOOKUP

XLOOKUP was used to retrieve employee names, department IDs, department names, managers, and salaries using Employee IDs and Department IDs.

### INDEX-MATCH

INDEX-MATCH was used as an alternative lookup method to retrieve employee information based on Employee ID.

### IFERROR

IFERROR was used to handle missing Employee IDs and display a user-friendly message instead of an error.

### Data Validation

Data validation rules were applied to:

- Department
- Employee Status

This helps maintain consistency and reduce incorrect data entry.

## Business Insights

1. Unique Employee IDs can be used to accurately combine information from multiple business tables.
2. XLOOKUP simplifies retrieving related employee and department information.
3. INDEX-MATCH provides a flexible alternative for lookup operations.
4. IFERROR makes lookup results easier to understand when records are missing.
5. Data validation improves data quality by restricting entries to predefined values.

## Outcome

The task provided practical experience with spreadsheet lookup functions and data validation techniques commonly used in data analysis and business operations.
