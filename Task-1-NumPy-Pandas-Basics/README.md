# Task 1 – NumPy & Pandas Basics

## Overview

This project demonstrates the basic usage of NumPy and Pandas for practical data analysis using the Titanic dataset.

## Objective

The objective was to practice NumPy array operations and Pandas DataFrame operations such as indexing, filtering, grouping, merging, and aggregations.

## Tools Used

* Python
* NumPy
* Pandas
* Jupyter Notebook / Google Colab

## Dataset

The Titanic dataset was used for the analysis. It contains passenger information such as passenger class, gender, age, fare, and survival status.

## NumPy Operations

The notebook demonstrates:

* Array creation
* Indexing
* Slicing
* 2D arrays
* Broadcasting

## Pandas Operations

The notebook demonstrates:

* DataFrame creation and inspection
* `loc[]`
* `iloc[]`
* Filtering
* `groupby()`
* `agg()`
* DataFrame merging
* Basic aggregations

## Key Findings

* Female passengers had a higher survival rate than male passengers.
* First-class passengers had a higher survival rate than lower classes.
* GroupBy was used to compare passenger groups.
* Multiple statistical aggregations were performed on passenger age.
* A left merge was used to add class information to the dataset.

## Outcome

This task helped build practical understanding of NumPy and Pandas, which are commonly used for data analysis and data science workflows.
