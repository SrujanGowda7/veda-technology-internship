# Task 21 – Confidence Intervals

## Objective

To calculate confidence intervals for population parameters using sample data and understand the uncertainty around statistical estimates.

## Tools Used

* Python
* NumPy
* Pandas
* SciPy
* Matplotlib
* Jupyter Notebook / Google Colab

## Dataset

A sample student-performance dataset was created using Python. It contains three numerical variables:

* Math Score
* Science Score
* Study Hours

## Tasks Performed

1. Created sample data using NumPy and Pandas.
2. Calculated the sample mean for three numerical variables.
3. Calculated confidence intervals at 90%, 95%, and 99% confidence levels.
4. Compared the widths of the confidence intervals.
5. Created a visual representation of the intervals.
6. Interpreted the results in plain language.

## Confidence Levels

The analysis used three confidence levels:

* 90%
* 95%
* 99%

As the confidence level increases, the confidence interval generally becomes wider because a larger range is required to provide greater confidence that the interval contains the true population parameter.

## Statistics Analyzed

Confidence intervals were calculated for the mean of:

* Math Scores
* Science Scores
* Study Hours

## Interpretation

A confidence interval provides a range of plausible values for a population parameter based on sample data.

The 90% confidence intervals were narrower than the 95% intervals, while the 99% intervals were generally the widest.

This demonstrates that increasing the confidence level generally increases the width of the interval.

A 95% confidence interval means that if the same sampling procedure were repeated many times, approximately 95% of the resulting intervals would contain the true population parameter.

## Conclusion

Confidence intervals are useful for understanding the uncertainty associated with estimates obtained from sample data.

This task helped strengthen my understanding of statistical estimation, confidence levels, sampling uncertainty, and statistical interpretation using Python.
