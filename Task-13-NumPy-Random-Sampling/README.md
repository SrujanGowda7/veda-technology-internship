# Task 13 – NumPy Random Sampling

## Objective

To generate random numbers and samples using NumPy and understand the importance of random seeds and reproducibility in data science experiments.

## Tools Used

* Python
* NumPy
* Jupyter Notebook / Google Colab

## Tasks Performed

1. Generated random integers using NumPy.
2. Generated random floating-point numbers.
3. Selected random samples from an array.
4. Created a small simulated student marks dataset.
5. Used a random seed to generate reproducible results.
6. Compared two results generated using the same seed.

## Random Data Generation

NumPy random functions were used to generate different types of random data, including integers and floating-point values.

## Random Sampling

A random sample of students was selected from an array using NumPy's random sampling functionality.

## Random Seed and Reproducibility

A random seed was set using `np.random.seed(42)`.

Using the same seed and the same random-generation process produced identical results. This demonstrates reproducibility.

## Importance in Data Science

Random numbers are useful for:

* Sampling datasets
* Simulations
* Machine learning experiments
* Creating synthetic datasets
* Testing algorithms

Reproducibility is important because it allows experiments to be repeated and verified.

## Conclusion

This task provided practical experience with NumPy random functions, random sampling, random seeds, and reproducibility. It strengthened the understanding of how random data is generated and used in data science experiments.
